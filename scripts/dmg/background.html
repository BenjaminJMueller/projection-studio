App auf „Programme“ ziehen.
Drag the app onto Applications.
2
App öffnen. macOS warnt, weil die App nicht von Apple beglaubigt ist. Dann Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen. Bis macOS 14 genügt Rechtsklick auf die App → Öffnen.
Open the app. macOS warns because it is not notarised by Apple. Then System Settings → Privacy & Security → Open Anyway. Up to macOS 14, right-click the app → Open.
3
Nur beim ersten Start nötig. Alternative per Terminal: siehe „Bitte lesen“.
Only needed on first launch. Terminal alternative: see “Read me”.
